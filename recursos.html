Hardening de Firewall, RAW & FastTrack

Genera una política de firewall de filtrado estricto en la tabla RAW para mitigar escaneos de puertos y DDoS sin saturar el procesador del router. 

Actúa como un Ingeniero Senior Certificado MikroTik (MTCNA, MTCRE, MTCSE).
Objetivo: Diseñar un script completo de firewall para MikroTik RouterOS v7 en un router de borde con WAN por ether1 y LAN por bridge1 (subred 192.168.10.0/24).
Requisitos estrictos:
1. Usar tabla RAW (/ip firewall raw) para dropear paquetes 'invalid', escaneos TCP SYN sin flags válidas y ataques de fuerza bruta hacia el puerto de WinBox.
2. Configurar FastTrack solo para conexiones establecidas y relacionadas del tráfico LAN-WAN.
3. Crear Address Lists dinámicas para aislar atacantes por 24 horas tras 3 intentos fallidos.
4. Entregar el código en un único bloque formateado con comentarios claros y advertencia de precauciones para no perder acceso.

Cálculo de Storage & Bitrate H.265+

Calcula con precisión matemática los Terabytes requeridos por códec, resolución, FPS y horas de grabación para cumplir con retenciones de 30 a 180 días. 

Actúa como Ingeniero de Proyectos de Seguridad Electrónica y CCTV.
Necesito calcular el almacenamiento requerido para un sistema NVR con las siguientes especificaciones:
- 16 cámaras IP de 4 Megapíxeles (2560x1440) a 20 FPS.
- 4 cámaras PTZ de 8 Megapíxeles (4K) a 25 FPS en accesos principales.
- Grabación continua 24/7 durante 60 días calendario.
- Códec: Smart H.265+ / Ultra 265 con tasa de compresión del 50%.
Calcula y entrega:
1. Tasa de bitrate promedio recomendada (kbps) por tipo de cámara.
2. Ancho de banda total de entrada hacia el NVR en Mbps.
3. Terabytes brutos y netos necesarios, añadiendo un 15% de margen de seguridad.
4. Configuración recomendada de discos duros (ej. Western Digital Purple / Seagate SkyHawk) y arreglo RAID.

IOT INDUSTRIAL & LORAWAN

Decodificador de Payloads Hexadecimales

Crea funciones JavaScript o Python limpias para decodificar cadenas de bytes crudos de sensores de campo hacia JSON para ThingsBoard o Home Assistant. 

Actúa como Desarrollador Especialista en Protocolos IoT y Telemetría LoRaWAN.
Tengo un sensor de presión y nivel de agua que envía su telemetría en una trama hexadecimal cruda (Payload Hexadecimal) a través de un gateway hacia ThingsBoard / ChirpStack.
Ejemplo de trama recibida: '017500A4026700E2030201'
Estructura del fabricante:
- Byte 1-2: ID de canal y tipo de sensor (01 75 = Presión en bar, factor /100)
- Byte 3-4: Valor de presión (00 A4 = 164 -> 1.64 bar)
- Byte 5-6: ID y tipo (02 67 = Temperatura en °C, factor /10)
- Byte 7-8: Valor de temp (00 E2 = 226 -> 22.6 °C)
- Byte 9-11: Estado de batería y alertas
Por favor escribe la función 'decodeUplink(input)' en JavaScript moderno compatible con el estándar The Things Network / ThingsBoard Data Converter, retornando un JSON estructurado y validado.

Failover Recursivo & Balanceo con Starlink

Configura conmutación por error (failover) con rutas recursivas hacia Cloudflare (1.1.1.1) y Google (8.8.8.8), integrando Fibra Óptica principal y Starlink de backup. 

Actúa como Ingeniero de Redes Especialista en MikroTik RouterOS v7.
Necesito configurar un failover ultra-confiable para una empresa en Santa Cruz con dos proveedores:
- WAN1 (Fibra Óptica Dedicada): ether1, Gateway 190.180.10.1 (Principal, prioridad 1)
- WAN2 (Starlink Business): ether2, DHCP client (Respaldo automático, prioridad 2)
Requisitos de ingeniería:
1. No usar solo el gateway físico del ISP (porque si el ISP pierde enlace internacional el puerto sigue UP). Implementar 'Recursive Routing' monitoreando 1.1.1.1 y 8.8.8.8 con check-gateway=ping.
2. Si WAN1 falla, conmutar en menos de 5 segundos hacia Starlink.
3. Cuando WAN1 se restablezca y permanezca estable por 30 segundos, volver automáticamente a la fibra sin flapeo de rutas.
4. Entregar el script completo probado para RouterOS v7.
